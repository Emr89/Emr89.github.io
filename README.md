# Eric Rupinski portfolio

This repair branch is based on the existing portfolio-revamp-v1 design. Its review PR is stacked onto that branch, preserving draft PR 1. No merge or deployment is authorized by this change.

Build a review candidate with `python3 scripts/build_review.py`, then run `python3 scripts/check_review.py`. Serve `dist/` locally to preview. The export excludes the existing public CFA review subtree by allowlist; it does not delete source files, rewrite Git history, revoke existing public URLs or make the already-public materials private.

Research case studies distinguish archived results from executed repairs and missing-data blockers. Counterpunch is a functioning independent prototype with a frozen test cutoff. The complete cross-repository progress record is delivered privately to the owner; private mentorship code is never copied here.

Release gates: owner review of CFA exposure/remediation, existing redesign, statistical caveats, resume details, access to the private Counterpunch repository and the remaining legacy presentation/link debt. The exporter is a review tool, not an enabled Pages deployment workflow.
