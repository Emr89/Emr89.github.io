Independent sports research

From Player Attributes to Match Outcomes

Soccer analytics that separates explanation, prediction and tactical hypotheses.

The question

I examined whether player and team attributes relate to match results using regression, random forests, dimensionality reduction and model comparisons. The work demonstrates analytical range across sports.

A match is the unit of validation

Player rows from one match share the same outcome. A model evaluated on other players from that match has not demonstrated performance on a new match. New validation helpers keep complete matches together and fit scaling only on training data.

What counts as an outcome?

The old WP variable is a home-win versus non-win indicator, with draws in the non-win group. It is not a measured probability. A new three-class label helper preserves home wins, draws and away wins for research that needs all three.

What remains

The source Excel files are absent. The cleaning reference error is repaired and helper tests pass; the original model pipelines still need integration with the new validation approach. No improved accuracy or tactical prescription is asserted.
